新增双周拟合与独立的假期模式。

- 常规可选每周或双周循环，按三小时时段拟合；缺少时段时显示覆盖数量并等待采集补齐。
- 假期按每天循环、每小时独立学习，从手动切换时开始积累，不混入常规样本。
- 可设置恢复常规的日期，从该日北京时间 00:00 恢复；跨日期规划也会分段使用两类用量习惯。
- 程序关闭期间到期时，下次启动自动恢复常规；手动切回常规会取消本次自动恢复。
- 两种模式各自保留最近 28 个所属日期的历史，切换边界的未知消耗不参加拟合。
- 统一采集、计算、测试与预览的模型接口，删除旧字段分支；小窗口的图表页面可滚动查看。
