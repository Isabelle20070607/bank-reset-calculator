首个 Windows x64 便携版。

下载 **BankedReset-0.1.0-windows-x64.zip**，完整解压后双击 **BankedReset.exe**。保留 `_internal` 文件夹；无需另装 Python、Qt 或 Node.js。

需要使用者自己的、已经登录的 Codex CLI。当前针对按周计量的 Codex 账户；首次运行会读取本地用量历史，历史不足时会提示继续积累。

- 自动采集剩余额度、reset 数量及到期时间，每 30 秒更新。
- 周一至周日分别拟合，比较 14 / 28 / 42 天的重置安排。
- 计入正常周刷新，以及使用 reset 改变后续刷新时间的影响。
- 不预设额外全局重置；实际发生后按新账户状态重新计算。
- 原生明暗界面、额度圆环、累计用量折线图及七天柱状图。
- 关闭到托盘继续采集，重复打开唤起已有窗口；可选创建桌面快捷方式。

下载包不包含开发者的登录信息、用量缓存或日志；界面预览采用虚构数据。完整使用与构建说明见仓库 README。
